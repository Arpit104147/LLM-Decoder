LLM Decodergguf

Workspaces

Local only. Source .gguf files are read, never written.

Open a model

Extracting a .gguf creates a workspace folder with metadata.json and the weights. Edit them here, in VS Code or Excel, then export a new .gguf.

CSV copy size
Only the top-left block of each tensor is written to weights/*.csv for VS Code and AI tools (full weights as text would be huge). The grid in the app still shows and edits every value.

KeyTypeValue

This is metadata.json, the same file VS Code and AI tools edit. Saving checks that it is valid JSON and that every value fits its type.

No AI: fixed rules + math on the weights (and llama.cpp for the logit lens).

Test the model

Questions with known answers. The model answers them, each answer is graded, and wrong answers can be fixed with a computed edit.

Pending changes

Everything that differs from the source file, whichever tool made the edit.

Build

Writes exports/<name>_edited.gguf. Unchanged tensors are copied byte for byte; edited ones are re-encoded.

Excel

One sheet per tensor, holding the same top-left block as the CSV files. Edit numbers, save, then import. Don't rename sheets or add/remove rows or columns.
